# Robin Liu

一張黑底的粉筆素描:只有一個棋盤。棋子可以拖到任何格子,**把對手將殺,就會有什麼被打開**。

用 Vite、TypeScript 和 [Three.js](https://threejs.org/) 製作。棋盤與棋子全部是程式生成的切面模型,沒有載入任何模型檔或圖片;粉筆素描的樣子是即時的後製效果,不是貼圖。

> 目前所有文字(名稱、簡介、專案、聯絡方式)都是**範例內容**,請依照下方「改成你自己的內容」替換。

## 玩法

畫面上只有棋盤、左上角的簽名、右上角的語言與音效開關,和左下角兩顆小圓鈕(重置棋盤、「?」)。

棋子沒有走法限制:任何一顆子都能拖到任何格子。拖到敵方棋子上是吃子,拖到己方棋子上是互換位置,兵走到底線會升變成后。網站不檢查走法,只看**盤面**:有沒有一方的王被將軍、而且無路可逃?造成將軍的是哪一種棋子?

| 用這顆棋子將殺 | 打開 |
| --- | --- |
| ♙ 兵 | 關於我 |
| ♘ 馬 | 專案作品 |
| ♗ 象 | 技能與經歷 |
| ♖ 車 | 聯絡方式 |
| ♕ 后 | 隱藏頁(成就牆與關於本站) |

- 平常是標準開局的自由沙盒,任何盤面只要出現上面的將殺就會打開對應的頁面。
- 畫面上沒有任何說明文字。左下角的「?」會擺出一道殘局,附一句謎語(例如「它從不走直線」),沒有答案、沒有跳過,這是「硬核模式」。隱藏頁的謎題在其他四道解完之後才會出現,而且沒有提示。
- 打開過的頁面會在畫面上方留下一個符號,點它可以再打開。還沒打開的頁面不會出現在畫面上。
- 頁面內容在打開之後才會下載(每個區塊是獨立的 chunk)。
- 進度存在瀏覽器的 localStorage,重新整理不會消失。
- 一共藏了 18 個彩蛋:吃特定的子、特殊盤面、鍵盤指令、終端機(按 `` ` ``)……進度只在隱藏頁看得到。

操作:滑鼠或觸控拖曳棋子,或先點棋子再點目標格;拖曳背景旋轉、滾輪或雙指縮放。鍵盤:方向鍵移動游標、Enter 或空白鍵拿起/放下、`Esc` 取消或關閉頁面。

## 畫風怎麼運作

場景先用一般的燈光照亮(顏色全是灰階,**亮度就是「要多少粉筆」**),再由 `src/three/sketch/` 重畫成黑底上的粉筆素描:

1. 把場景畫三次:受光的畫面、法線與深度。
2. 合成時,深度或表面方向突然改變的地方畫粉筆線(輪廓畫得重,切面之間的邊畫得輕),線會輕微抖動、補畫一次,像手畫的。
3. 越亮的地方排線越多:先是一個方向,最亮處才交叉,每一筆各自決定要不要出現,所以排線是一筆一筆變密、而不是淡入。棋盤(朝上的面)與棋子(直立的面)的排線角度不同,兩者不會糊在一起。陰影處什麼都不畫,就是黑底本身。
4. 有顏色的東西(游標、選取框、將殺的光環)被當成橘色的標記筆,疊在上面。
5. 燈光落在棋盤中央,往四周漸暗,並且會稍微跟著滑鼠偏移;畫面開頭是從中央一筆一筆「顯影」出來的。
6. 輔助線(`guides.ts`):棋盤外的兩圈圓與刻度、棋盤邊線與對角線的延長、定位用的十字,都是自己會抖的線,開頁時一筆一筆畫出來。它們用場景的深度比對,所以會被棋盤擋住。

想調畫風,改 `src/three/sketch/pipeline.ts` 裡的 `DEFAULT_LOOK`(紙色、粉筆色、排線疏密與各方向出現的亮度、輪廓粗細)與 `src/three/lighting.ts` 的燈光。`npm run dev` 之後打開 `/lab.html` 是棋子實驗頁,黑白兩排並排、可用 `window.__lab` 移動相機;`window.__lab.sketch.setDebug(true)` 會顯示場景實際的亮度,方便調燈光。

字型是 [Caveat](https://fonts.google.com/specimen/Caveat)(標題)與[霞鶩文楷 TC](https://fonts.google.com/specimen/LXGW+WenKai+TC)(內文),從 Google Fonts 非阻塞載入;沒載入時退回系統字型。

## 棋子的比例

照真實的 Staunton 比例做(比賽用的王約 1.7 個格子高,底座直徑約身高的 40%),單位是棋盤的一格:

| 棋子 | 高度 | 底座直徑 |
| --- | --- | --- |
| 王 | 1.78 | 0.72 |
| 后 | 1.55 | 0.68 |
| 象 | 1.44 | 0.66 |
| 馬 | 1.35 | 0.66 |
| 車 | 1.12 | 0.66 |
| 兵 | 0.96 | 0.58 |

形狀在 `src/three/pieces/`:`toolkit.ts` 的 `turnFacet` 把一圈圈的環旋轉成切面(相鄰兩環錯開半格,面就會變成菱形,像切割過的石頭),`staunton.ts` 是王后象車兵,`knight.ts` 是馬。`tests/pieces.test.ts` 會檢查這些比例沒有跑掉。

## 開發

需要 Node.js 22.12 以上。

```bash
npm install
npm run dev        # 開發伺服器
npm test           # 單元測試
npm run typecheck  # 型別檢查
npm run build      # 正式建置到 dist/
npm run preview    # 預覽建置結果
```

## 改成你自己的內容

| 想改什麼 | 檔案 |
| --- | --- |
| 名稱、一句話介紹、Email、GitHub | `src/content/profile.ts` |
| 關於我 | `src/content/about.ts` |
| 專案作品 | `src/content/projects.ts` |
| 技能與經歷 | `src/content/skills.ts` |
| 聯絡方式頁 | `src/content/contact.ts` |
| 隱藏頁的文字 | `src/content/secret.ts` |
| 介面文字(提示、謎語、彩蛋、終端機) | `src/i18n/zh-TW.ts`、`src/i18n/en.ts` |
| 配色 | `src/theme.ts`(CSS 變數會從這裡同步;3D 場景的顏色是灰階,深淺就是粉筆的多寡) |
| 畫風(紙、粉筆、排線、輔助線) | `src/three/sketch/` |
| 棋子、棋盤的形狀 | `src/three/pieces/`、`src/three/boardView.ts` |
| 哪顆棋子對應哪個區塊 | `src/content/sections.ts` |
| 殘局 | `src/chess/puzzles.ts` |
| 彩蛋清單 | `src/game/eggDefs.ts`,再到兩份字典補 `egg.<id>.name/toast/desc` |

每個內容檔都有繁中與英文兩份,改完把範例提示(「範例內容:請編輯……」)那一行刪掉即可。

改殘局時請跑 `npm test`:測試會把「任何一顆子拖到任何格子」全部試一遍,確認每題都能一步解開、而且**只有目標棋子**能解(例如兵被拖到底線會升變成后,可能意外造成后將殺,測試會抓到)。

## 部署到 GitHub Pages

1. 到 repo 的 **Settings → Pages**,把 **Source** 設成 **GitHub Actions**。
2. 把程式推到 `main`,`.github/workflows/deploy.yml` 會跑型別檢查、測試、建置,然後部署。
3. 網址會是 `https://<帳號>.github.io/<repo 名稱>/`。

這是 project site,資源路徑需要 `/<repo 名稱>/` 前綴,workflow 已經用 `BASE_PATH` 帶進去(分享預覽圖用的 `SITE_URL` 也是)。如果你用自訂網域,或 repo 名稱是 `<帳號>.github.io`,請在 workflow 裡把 `BASE_PATH` 改成 `/`,並把 `SITE_URL` 換成你的網址。

分支與 PR 只會跑檢查、不會部署。

## 專案結構

```
src/
  chess/     規則引擎:任意盤面的將軍/將殺/逼和偵測、自由走子、殘局(純 TypeScript,有測試)
  three/     場景:棋盤、棋子模型(pieces/)、相機、輸入、特效
    sketch/  粉筆素描:後製管線與著色器、輔助線、飄浮的粉筆灰
  game/      遊戲流程:走子動畫與判定、彩蛋、終端機指令、按鍵序列
  content/   各頁的內容(打開後才動態載入)
  ui/        HTML 介面:簽名與小圓鈕、符號列、側邊面板、終端機、提示
  i18n/      繁中與英文字典
  state/     進度存檔
tests/       Vitest
```

## 注意

- 解鎖是純前端的小遊戲,不是安全機制:頁面內容是公開的靜態檔案,只是不會在一開始就下載。
- 分享連結時的預覽圖是 `public/og.png`(1200×630),目前拍的是範例內容的畫面。改完自己的內容後,請重拍一張換掉。預覽圖需要完整網址,所以只有在建置時有設定 `SITE_URL`(workflow 會自動帶入)才會寫進 HTML。
- 瀏覽器不支援 WebGL 時會顯示後備頁面,只有名稱與聯絡方式。
- 畫面是逐像素重畫的,高解析度螢幕上如果持續掉幀,繪製解析度會自己調低。
